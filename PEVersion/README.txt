================================================================================
PEVersion — 双击即玩的单机离线版 OpusMC
================================================================================

直接双击本目录里的 game.html 就能玩，不需要启动服务器、不需要联网、
不需要装任何东西。也可以把整个 PEVersion 目录上传到 webcatx 之类的静态托管。

--------------------------------------------------------------------------------
和原版 probe/ 的区别
--------------------------------------------------------------------------------

1. 音效已全部内嵌
   js/sounds.js（56MB）里装着 4849 个 m4a 的 base64。
   游戏在 file:// 协议下会自动加载它（audio.js 里写好的），
   所以双击打开也有完整音效，不是合成音兜底。
   重新生成：python tools/build_pe_sounds.py PEVersion

2. 多人联机已禁用；主菜单已精简
   「多人游戏」保留但不可点击（enabled: false）。
   登录、公告吊牌、股东名单、签到、左右下角图标、底部署名文字
   全部去掉；「模组」按钮不再要求登录，直接打开。
   本版本没有联机能力，请勿尝试。

3. 内置模组正常加载
   mods.js 里加了一行：没有 ?modtest / 下载记录时，把 MODS_ALWAYS 直接计入 active。
   否则原版逻辑下 active 为空，7 个内置模组（匠魂、农夫乐事、连锁挖矿等）
   不会加载。现在 16 个 data.js / code.js 都会正常写入。

4. 地形在页面内生成
   file:// 下浏览器不允许 Worker，游戏自动降级成页面内生成，
   首次进世界会卡一点，这是浏览器限制，不是 bug。

--------------------------------------------------------------------------------
怎么验证
--------------------------------------------------------------------------------

用 Chrome 直接打开：
  file:///.../PEVersion/game.html

开发者工具控制台里应该看到：
  - SOUNDS.files 有 4849 个键
  - Mods.active 有 7 个 id
  - 主菜单「多人游戏」按钮点击无反应

--------------------------------------------------------------------------------
目录说明
--------------------------------------------------------------------------------

  game.html         入口，99 个 script 都带 ?v=47685r1（防缓存）
  js/               游戏逻辑（含内嵌音效 sounds.js）
  mods/             7 个内置模组
  sounds/           原始 m4a（已内嵌进 js/sounds.js，保留仅为可重建）
  Logo/             Mojang logo

  tools/（在上一级 opusmc-inject/）
    build_pe_sounds.py      重新生成内嵌音效包
    fetch_sounds.py         重新抓取音效原件
    extract_vanilla_assets.py  从编译产物 dump 贴图

================================================================================

5. 内置客户端 HUD（原油猴脚本 opusmc-hud.user.js v1.32.0）
   PC 进入世界后按 Insert 打开经典面板，` 键开悬浮面板，M 开大地图。
   手机 / 触屏进入世界后点右侧「客户端」按钮打开面板。
   首次进世界会在聊天栏提示一次。
   由 tools/integrate_hud.py 从 opusmc-hud.user.js 生成：
   js/comet-hud.js（HUD 本体）+ js/comet-mobile.js（提示与手机按钮）。
   材质包用独立插件 opusmc-resourcepack.user.js v1.5.0（js/comet-resourcepack.js），
   HUD 里那份旧材质包已剥离；游戏菜单「资源包…」或 Alt+R 打开。
   由 tools/strip_hud_resourcepack.py 生成，改主脚本后重跑这两个脚本。
   注意：HUD 脚本 571KB、音效包 57MB，首次加载会慢几秒。
   网页版没有 Tampermonkey，GM_* 相关功能（来源伪装、跨站账号同步）
   自动降级，不影响单机玩法。
